# SIM7600 独立硬件模块

此模块不导入或调用 LLM、ASR、TTS，不启动模型服务、不改变 APN、网络模式或固件。
Windows 原生进程访问 AT / USB Audio 串口，不依赖 Docker 串口透传。
浏览器语音控制台仍与硬件独立；这一阶段通过 Python API 和 CLI 测试。

## 安装与只读检查

仓库根目录执行：

```powershell
uv pip install --python .venv/Scripts/python.exe --no-build-isolation -e ".[hardware]"
.venv/Scripts/python.exe -m voice_agent.sim7600_cli ports
.venv/Scripts/python.exe -m voice_agent.sim7600_cli status
.venv/Scripts/python.exe -m voice_agent.sim7600_cli calls
.venv/Scripts/python.exe -m voice_agent.sim7600_cli watch --seconds 30
```

安装后也可使用 `.venv/Scripts/sim7600.exe`，或 `scripts/sim7600.ps1 status`。
默认按 Simcom 描述发现 AT PORT / Audio；出现多个候选必须明确指定端口，
不会随便选择。全局 `--at-port COM12 --audio-port COM10` 必须放在子命令之前。
端口可能变化，文档中的 COM 号仅是本次设备实例。其他串口工具须先释放端口。
status 读取 AT / CPIN / CSQ / CEREG / CPSI；不读取 IMEI 或本机号码。
LTE 注册只表示拨号前置条件，不等同于保证 IMS 语音可用。

## 显式通话测试

以下命令会实际接听/拨号；由操作者选择测试号码。程序不会自行选择联系人或拨打示例号码。
先用手机拨入模块，来电振铃时执行接听（默认不自动接听）：

```powershell
New-Item -ItemType Directory -Force local-data | Out-Null
.venv/Scripts/python.exe -m voice_agent.sim7600_cli answer --seconds 20 --record local-data/incoming-test.wav
```

主动外呼需要明确号码：

```powershell
.venv/Scripts/python.exe -m voice_agent.sim7600_cli dial <测试号码> --seconds 20 --record local-data/outgoing-test.wav
```

加 `--play local-data/test-tone.wav` 可在录制下行的同时向对方发送 WAV。
仅支持 8kHz、单声道、16-bit PCM WAV；本阶段拒绝其他格式，不偷偷重采样。
play 本地测试文件不会使用麦克风，也不是回声桥接。对端须确认实际听到内容。
WAV 输出不得已存在，避免覆盖录音；可按日期命名。

上述 dial / answer 会等待接通（默认最多 60 秒），保持通话到 --seconds 上限或
对方挂断，最终尝试关闭音频、挂断和 CPCMREG=0。Ctrl+C 同样进入清理。
不要终止整个 Python 进程来代替挂断；USB 掉线或命令超时时无法保证清理成功，
程序会明确报错，需要检查电话状态。单独的挂断命令：

```powershell
.venv/Scripts/python.exe -m voice_agent.sim7600_cli hangup
```

CLI 使用 AT 端口期间，不要同时启动第二个操作命令。持续 watch 会占用 AT 口；
先 Ctrl+C 退出 watch 再接听。长驻应用使用下方同一个 ATTransport 同时收事件与发命令。

## Python API

```python
from voice_agent.sim7600 import ATTransport, Sim7600

with ATTransport() as transport:
    modem = Sim7600(transport)
    print(modem.health())
    print(modem.calls())
    # modem.dial(number) / modem.answer() / modem.wait_active(timeout=60)
    # modem.usb_audio(True) / modem.usb_audio(False) / modem.hangup()
    # transport.events.get(timeout=1) -> {"time": ..., "line": "RING"}
```

`PCMAudio`（voice_agent.sim7600_audio）提供 record(path, seconds)、play(path)、
cancel()、close()，可分别在两个线程调用 record/play。接通后打开 Audio 串口再启用
CPCMREG；外层调用者负责在 finally 中停音频、关闭 CPCMREG、挂断。
cancel 后应重建 PCMAudio 实例再开始新的播放。传输格式固定 8kHz/PCM16/mono/LE。

ATTransport 单一读取线程持续解析 CRLF 行，命令按锁串行执行，RING / VOICE CALL /
NO CARRIER 等异步事件进入独立队列。命令查询前不清空输入缓冲，避免漏事件。
队列最多 256 条，溢出计入 dropped_events；调用者应持续消费。原始事件可能包含
对端号码，业务日志应按需脱敏。命令超时/断线后 transport 拒绝继续发命令，需关闭并
重新连接，避免迟到的 OK 被误算作下一次响应；不自动重拨。通话状态以 CLCC 为准。

PCM 接收跨串口读块保留奇数字节尾部，WAV 只写完整 PCM16 样本。上行每帧最多
20ms 并按实时节奏发送；取消会清理主机输出缓冲，不能保证模块内部缓存立即停止。
没有实现 VAD、自动增益、AEC、自动重连或无人值守接听。
